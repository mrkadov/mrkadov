# KADO

Melankolik rap. Cinematic boom bap.

Söz bir süs değil, sahne ve kancadır. Suno bir piyango değil, aşamalı prodüksiyondur.

## Söz

**[SÖZ Sistemi](soz-sistemi.md)** — brief, örgü, yazım, kalite kilidi.

> Önce sahne ve hikâye → sonra nakarat kancası → sonra verse flow → en son süs.

**SÖZ**

- **S** — Brief
- **Ö** — Örgü
- **Z** — Yazım
