# Gelme Bu Gece

KADO lane’inde SÖZ sisteminin tam tur örneği. KA-1 kimlik kartındaki fikir: gece yarısı, kapıya gelen geçmiş.

## Brief

```
Konu: Kendi evinin eşiğinde durmak
Müzik türü: cinematic emotional boom bap
BPM: 90
Duygu / atmosfer: gece, samimi, karanlık, yüzleşme
Vokal: erkek, close-mic verse, geniş nakarat
Argo: düşük
Hikâye: Gece üçte kapı sesi sanır. Geçmiş içeride, kendisi dışarıda.
Bölüm: tam yapı
```

## Örgü

- Sahne: kısık lamba, soğuk çay, kara ekran, askıdaki ceket, boş yastık, oynamayan tokmak
- V1: sesi dışarı sanır
- Nakarat: kanca + ters yüz (`sen içeridesin, ben eşikteyim`)
- V2: ev hâlâ onun saatinde; kilidi kendine çevirmiştir
- Köprü: tokmak onun parmağıdır
- Outro: sahne aynı, kişi değişmiş

Kafiye: anlam öncelikli. Nakarat kısa ve eşit. Verse’te iç kafiye var, zorlama uyak yok.

## Kalite kilidi

1. Doğal konuşma: evet. “kader / gözyaşı / yalnızım” yok.
2. Zorlama kafiye: yok. `duvara / hâlâ` eğik; anlam taşıyor.
3. Flow: nakarat 5 hecelik kanca; verse barları okunarak kontrol edildi.
4. İlerleme: V1 yanlış anlama → nakarat ters yüz → V2 bedel → köprü itiraf.
5. Nakarat kancası: `Gelme bu gece`.
6. Alıntı satırlar:
   - Sen içeridesin, ben eşikteyim
   - Tokmak yok, ses var yine
   - Kendimi dışarı kilitledim
   - Belki tokmak benim parmağımdı
   - Kapı yerinde / Ben değilim
7. Tekrar: kanca bilinçli; verse’te aynı cümle yok.

## Style (KA-1 Aşama A)

```
Emotional cinematic boom bap, 90 BPM, melancholic piano, distant atmospheric violin, dusty organic drums, intimate male rap vocal. Begin lonely and spacious, grow into a wide emotional chorus, then return to controlled energy. Dark, nocturnal, melancholic, professional arrangement, warm low end.
```
