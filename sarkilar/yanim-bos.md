# Yanım Boş

KADO lane’inde duygusal boom bap. Kapı ve okundu değil: gece yol, sağ koltuk, ısıtıcı hâlâ açık.

## İş kartı

```
Sanatçı / lane: KADO — cinematic emotional boom bap
Konu: Boş yolcu koltuğu
Dinleyici: gece, kulaklık, araba / yalnız
Piyasa: Spotify kimliği + kısa video (8 sn kanca)
BPM: 90
Duygu / atmosfer: soğuk netlik, hareket, duramama
Vokal: erkek, close-mic verse, geniş nakarat
Argo: düşük
Hikâye: Gece üçte aynı üç sokağı dönüyor. Sağ koltuk boş. Isıtıcı sağda açık.
Yasak: kader, gözyaşı, yalnızım, kırık kalp, geceler uzun
```

## Kanca tahtası

```
A: Yanım Boş
B: Sağ Koltuk
C: Cam Buğu
Kazanan: Yanım Boş
Neden: 3 hece, koro, karar. Sağ koltuk verse’te nesne olarak durur.
Ölenler: Sağ Koltuk bağırılmaz. Cam Buğu atmosfer, iddia yok.
```

## Pitch

Gece üçte aynı üç sokağı dönüyor. Sağ koltuk boş, ısıtıcı hâlâ açık. 90 BPM cinematic boom bap. Kanca: Yanım Boş.

## Örgü

- Sahne: far kısık, cam buğu, sarkık kemer, sağ ısıtıcı, yarım kalan radyo
- V1: çıkar, gider gibi yapar; bakacak yüz yoktur
- Nakarat: kanca + yer (`sağ taraf senin`)
- V2: saç teli, ev de boş, kendisini yola kilitler
- Köprü: belki koltuk hiç dolmadı
- Outro: far, buğu, koltuk, ben

## Kalite kilidi

1. Doğal konuşma: evet. “kader / gözyaşı / yalnızım” yok.
2. Zorlama kafiye: yok.
3. Flow: kanca 3 hece; verse yüksek sesle okundu.
4. İlerleme: V1 çıkar → nakarat yer → V2 bedel → köprü itiraf.
5. Nakarat kancası: `Yanım boş`.
6. Alıntı: yukarıdaki liste.
7. Başlık ürün: kısa iddia.
8. 8–15 sn: nakaratın ilk bloğu.
9. Katalog ayrımı: Okundu ev/telefon; bu parça araba/yol.
10. Paket: Style ayrı dosyada.
